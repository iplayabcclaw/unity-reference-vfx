# 从脚下向外龟裂：连通裂网与中央碎岩

> 类型：算法参考。适用：带明确震心、内低外高、中央细碎而外围较大的地裂表现。状态：根据震地狂潮当前代码整理；C# 编译通过，按用户认可的俯视模拟简化后的游戏造型尚未实机验收。参数为该效果的设计起点，不是所有地裂的统一规格。

## 先分清要改的层

| 用户所指 | 实际载体 | 修改位置 |
| --- | --- | --- |
| 地面上的碎岩更小、更密 | 有厚度的岩面网格 | 增加局部划分种子、细分多边形、调整块间内缩 |
| 飞起来的碎石更小、更密 | Mesh 粒子 | 尺寸、数量、发射位置及飞行高度 |
| 龟裂中心明显、向外开裂 | 主裂隙拓扑＋岩面高度＋展开时钟 | 中心种子结构、径向高度曲线、按距离展开 |

仅缩小并增加飞散粒子，地面大岩块仍不会变小。中心粒子太低还可能被岩面深度遮住。反馈“没变化”时先核对承担视觉识别的载体，不要继续累加粒子，也不能只因修改了参数或编译通过就认定观感已改变。

## 1. 统一坐标与正式中心

在正式地面中心建立局部 XZ 平面，归一化水平位置为 `p`，`r = length(p)`；水平尺寸乘真实效果半径，高度另乘人物或约定美术尺度。自中心震地取正式施法原点；固定区域生成后不擅自追随人物移动。随机旋转围绕该原点，裂网、岩面、压力和飞石共用变换。

“从中心向外”同时包含空间结构和出现顺序：全域随机裂网加径向显隐，只改变时间，完整展开后仍可能没有明显震心。

## 2. 连通分区与放射主裂隙

使用半平面裁切生成 Voronoi 分区。种子 `si` 对其他种子 `sj` 的保留区域为：

```text
dot(p, sj - si) <= (dot(sj, sj) - dot(si, si)) / 2
```

从覆盖效果的大凸多边形开始，逐个裁切。跨边界的交点用两端有符号距离插值，结果少于三个顶点则无有效面。

让种子间距随离震心的距离增加，得到中央细碎、外围大块的单层分区。当前粗略版使用有界拒绝采样：至多1200次候选、112个种子（包括外部约束点），最小间距为 `0.075 + 0.14 * 两点平均半径`。这些数值是本效果的成本上限，不是视觉验收结论。不要为制造震心把所有种子固定在同一圆周；那样容易形成切披萨式扇形骨架。

按起伏的不规则外边界选择完整岩块，再拒绝超出最大外界的块，不把所有多边形裁成同一圆周。三组岩面渲染批次随机分配，不代表三个空间扇区。

## 3. 相邻岩块共享锯齿边

以相邻种子的无序索引对作边键，例如 `(minIndex, maxIndex)`。同一条边只生成一次，两侧按相反顺序使用同一组点；不能各自随机，否则裂隙会重叠、分叉错位或漏面。

沿边分段，在垂直方向扰动，端点扰动为零。振幅同时受边长和两侧种子到边的距离约束。逐段核对两侧扇形三角的叉积方向；发生翻折时降低这条边的扰动，仍无法合法生成时明确报错。浮点近重合点、零长度边和多种子共圆的交点需要按几何语义处理，不能靠吞异常继续上传。

主裂光沿这张共享边图生成，宽度内大外小；压力雾与飞石也从该图采样。实例主裂光半宽从0.020向外收至0.002，普通细缝宽度为其22%，并带局部随机变化。裂光是 recessed seam 的表现层，不用独立直线叠加伪造与实体无关的裂纹。

## 4. 沿实际块边形成主缝和支缝

将共享边端点合并成邻接图；浮点端点按适合当前归一化尺度的精度合并。主缝从一小片椭圆震心附近起步，沿邻接边向外选择路径，而不是另画穿过岩块表面的直线。

```text
score = dot(edgeDirection, preferredDirection)
      + 0.8 * radialAdvance / edgeLength
      - 0.8 * existingMainWeight
```

排除本条路径已用边、零长度边和明显向内回折的边。实例七个方向各追踪最多24条边，途中再追踪一次偏转方向、半权重的支路，支路不继续递归分叉。不同路径可以汇合，不保证每条都到达相同半径；这种长短差异保留自然的不齐外缘。主缝与普通缝共用实体边，只改变裂光的宽度和亮度。

中央碎块数量由同一分区的局部种子间距控制；顶点向各自块中心小幅内缩留下缝隙。当前实现不再维护七瓣父块和每瓣24次二级划分。需要更细的版本时，先增加局部种子密度并检查成本，不通过增加飞散粒子替代岩面分区。

## 5. 内低外高且保留外围高度

对每个岩面顶点计算高度曲线，而不是只降低一个中心点或单块中心；否则随机高块仍会遮掉震心。实例为：

```text
q = clamp01((r - 0.26) / (0.76 - 0.26))
profile = pow(q*q*(3 - 2*q), 1.6)
y = lerp(0.006, originalRoughHeight, profile)
```

内侧26%半径近乎贴地，随机高差随 profile 恢复，76%以外的非边界岩面保留原高度范围。实际外沿需要另做回落：统计边两侧可见岩块，只有一侧的边是裸边；对顶点计算到裸边线段的最小距离，在过渡带内压回地面，最外点可略低于地面并由地板裁切衔接。不要让最大高度直接终止在外沿。`0.006` 为人物高度单位中的地面岩面高度，不是世界米数。侧壁底部须低于顶部；地面偏置、下沉动画、镜头侧压低和 Shader 地板裁切应一起核对，避免低矮中心刚出现就被裁掉。

飞石可共用 profile，但分别控制尺寸和扬起高度。实例中心尺寸为原飞石的10%、扬起高度为4%，外围恢复原值。中心加密用独立的内圈裂隙采样表，保留全域采样配额；高低档交错选取两类粒子，防止低档只留下其中一类。加密粒子仍不能代替第4节的岩面细分。

裸边侧壁不生成红色断口，只有双侧有岩块的内部缝隙发光；否则连续红边会把整个效果勾成一张贴片。少量主裂缝抵达外沿后继续以低亮、渐细的短折线延伸，长度不同并在末端收尖，使实体范围和裂缝范围错开。当前每布局至多7条延伸、每条3段，使用原裂光批次，不增加渲染器。半平面裁切决定外轮廓，并不自动解决外轮廓与原地面的衔接；材质色差仍需结合实机图判断。

## 6. 径向展开、材质和生命周期

用同一暂停兼容局部时钟驱动岩面、裂光和压力显隐：

```text
spread = clamp01(age / spreadDuration)
reveal = smoothstep(-frontSoftness, 0, spread - r)
particleDelay = sourceRadius * spreadDuration + smallJitter
```

实例展开占单波寿命45%，裂光亮峰也按 spread 向外推进。显隐只控制装饰出现，不改变正式伤害波次、范围或 AI 时序。岩面写深度，用侵蚀／下沉退场；裂光和雾使用适合暗底与局部亮部的透明混合。低特效保留主裂网和中央岩面细分，优先减少伴随粒子。

当前粗略版缓存8份布局，每边2～6段，压力雾至多7片、每片12段×7行；飞石／尘粒／细屑为48／24／20个，低档各减半。有限布局缓存、独立表现随机源、固定缓冲和对象池可复用。几何不要逐帧重新裁切。使用缓存时核对当前预览是否已重建修改后的布局；未确认缓存陈旧，不要把所有“没变化”都归因于缓存。

## 移植与验证边界

本算法不依赖特定项目类名。震地狂潮中的对应职责为 `HornRiftGeometry`（密度分区、TraceMainFractures、高度曲线）、`HornRiftVfx`（装配、波次内显隐、粒子）、`HornInwardRift.shader`（材质与径向揭示）。移植时接目标工程正式事件与资源生命周期，不复制其战斗结算。

算法检查关注有限顶点、正面积、共享边一致、主缝沿真实邻接边连接及中心/外围高度边界；不能用源码包含方法名证明正确。遵循目标项目验证限制，分别说明 C# 编译、几何运行验证、Shader 验证和实际画面验证。此参考记录的是已接入算法，不表示最新造型已得到用户验收。
