# 参考图还原与分层配方

类型：skill 工作方法。适用于按图片还原、分析还原偏差或结合现有材质后端；不表示任何技能已通过实机验收。技术装配见 [Shader 与特效装配](shader-and-assembly.md)，挂点和正式事件边界以 `SKILL.md` 与目标工程的适用规则为准。

## 把图片变成可核对的目标

打开用户选定的实际图片；多版本时确认选用文件，不用提示词代替图，也不自行重生成概念图。先找决定辨识度的特征，再决定实现方式。避免只记“金色狮头”“红色斩击”就开始写代码。

新生成／改版参考图默认按 [多部分参考图与素材拆解](multi-panel-reference.md) 展示整体与关键素材。先用整体格确定组合关系，再把拆解格对应到实际层；分格中放大的部件不能按其画面占比直接推导运行尺寸。沿用既有单图时继续按下面的方法拆解，不因新格式重做已认可资源。

- **投影形状：** 主体外轮廓、端点、最大宽处、弧腹或转折、内部空腔、断裂间隙。必要时用主体包围框内的归一化坐标记关键点；包围框只是美术测量基准，不是伤害范围。
- **比例：** 长宽比、厚薄变化、主体与伴随层的大小、空腔与实体比例、亮边相对宽度。能确定的写具体比值，不能确定的标估计；不凭空规定所有技能通用的误差阈值。
- **明暗与介质：** 暗部／中间调／亮部的分布，高光在哪里集中，哪些位置仍能看见背景。亮度排序与亮部覆盖往往比颜色名更能决定观感。
- **空间与阶段：** 镜头倾角、近似正交或透视、物体朝向、前后遮挡，以及这张图对应蓄力、释放、命中还是持续阶段。单帧里的飞散物可能是先前生成的余迹，不代表同时发射或永久存在。

图中没有角色时不凭空推导绝对米数；使用项目人物尺度或真实区域确定世界尺寸，再保留图中的视觉比例。视角不同的参考图先提取造型，不能为贴合图片而改变真实弹道、区域或用户指定挂点。地面受光、阴影和背景不算主体素材，也不自动要求增加灯或改全局管线。

将上述信息压成简短的识别目标与分层配方即可，在对话或已有任务记录中表达；不为每次任务额外创建检查报告、配方文件或截图目录。

## 生产素材选择

所有生产路线遵守 [禁止贴图约束](../SKILL.md#硬性约束禁止贴图)。参考图片仅用于测量与拆解，不能导入为特效图集、透明素材或序列帧。

| 图中结构 | 无贴图生产路线 | 不能代替它的做法 |
| --- | --- | --- |
| 稳定切面、厚度、跨视角结构或明显自遮挡 | 有相应轮廓、截面和细节的网格，配合顶点色与程序表面材质；可使用不依赖贴图的建模资源 | 通用锥体换色或将完整主体画在平面上 |
| 复杂薄层、兽首或幽魂 | 分层立体网格、真实凹凸与空腔，以及对应顶点／骨骼运动 | 去背景图片、billboard、交叉或分层贴片 |
| 翻卷火焰、烟尘、液体撕裂 | 闭合焰瓣、动态曲面、网格粒子与直接计算的程序密度场 | 序列帧、流体贴图或仅平移噪声 |
| 刀光、血膜、羽毛、纹章 | 独立边缘几何、分支／切面结构、顶点色和解析遮罩 | 图片遮罩或只增加 Bloom |

先检查实际几何能否表达关键点、孔洞、边缘与比例，再补程序材质。缺少结构时补建模型或几何，不生成透明生产图片。模型仍是近似时明确缺失的识别特征；素材制作不自动授权购买插件或操作 Editor。

## 公共造型的复用边界

复用以关键轮廓、空间结构和材质能力匹配为前提。普通实体盾可共用少量形状并配置配色、描边与比例；如果参考图改为靠封闭穹顶、切面和透明空腔辨识的水晶罩，应使用能表达该结构的主体资源或几何；现有参数化实现能满足时继续复用，不能用几块通用盾围起来替代。公共缓存、上色和生命周期仍可复用，不为新轮廓另建整套特效框架。不要把某次选定的形状数量或配色写成所有技能的限制。

## 每层的实施配方

按视觉职责组织分层配方，每层须对应图中可见内容或技能必要阶段，不为了凑层数新增法阵、光圈、灯光或装饰。

| 字段 | 要落实的内容 |
| --- | --- |
| 视觉职责与依据 | 对应图中哪个部位，承担轮廓、内部介质、局部亮部还是伴随变化 |
| 几何与空间 | 载体、轴向、挂点、相对尺寸、厚度、空隙、遮挡与跟随方式 |
| 实际素材 | 资源路径、网格、动画与程序 Shader 用途；已具备、需制作或占位分开 |
| 材质 | 当前 Shader 与有效属性、混合、透明度、暗部／中间调／高光、独立发光强度、深度与排序 |
| 运动 | 各层生成位置与流向、程序场迁移和几何形态变化的区别、随机差异与寿命 |
| 时序 | 正式触发事件、延迟、起落曲线、代表帧、停止发射、退场及取消清理 |

参数用于实施，不能冒充图片中的事实。世界尺寸和正式阶段时长读取项目，推断出的视觉值标为初始设计值；有意义时给关键点曲线，不只给“逐渐变亮／淡出”。颜色的基础色、HDR 强度和最终显示色分开。

只有相关正式阶段才列时间轴，图中的高峰落实到确定的视觉年龄或正式阶段。校准时固定视觉随机条件，避免每次看的其实是另一批散布。运行时仍保持合理的独立视觉变化，不消耗战斗随机。

主体结构优先实现，随后补内部素材、明暗与次级变化；复杂特效逐层核对职责。已有正式事件与对象池继续复用，不另建一套只在独立演示场景工作的完整执行协议。

## 材质后端选择

按目标工程现有 Shader、Particle System、Shader Graph、VFX Graph 或已安装插件的能力选择，不假定任一后端存在；本 skill 的分层方法不依赖插件。

- 将材质拆为渲染配置、形状组合、颜色／透明与 UV 运动。明确各遮罩的相乘／相加，先保证单层轮廓，再组合多层。
- 属性名、渲染功能与关键字以实际 Shader 为准，不把示意参数当 API。所需变体应被构建收录；属性归零不一定省去计算。
- 不自动替换已有有效材质、导入整套外部工程、开启全局后处理或要求先生成概念图。缺少某种能力时选择替代载体，并说明视觉差异。

## 差异修正

有用户提供或项目许可获得的实机画面时，将相同代表阶段、相近镜头和裁切对齐后比较。分开看造型与背景贡献，不直接拿整张背景的像素差衡量主体，也不把更强 Bloom 当作更高相似度。

| 差异 | 优先调整 |
| --- | --- |
| 主体类别相同，但看起来像另一种造型 | 轮廓关键点、长宽比、负空间、厚度和前后层；必要时更换主体素材／几何 |
| 主体正确，内部像塑料片、噪声膜或霓虹线 | 几何细节、程序场结构、材质暗部、透明度分布、亮部覆盖及混合 |
| 某一瞬间接近，但播放时读不清 | 到达高峰的时刻、可读停留、各层的起落与退场，遵循正式时序 |
| 穿身、位置偏、朝向反或太大 | `SKILL.md` 的挂点、坐标、镜头投影与尺寸规则 |

每轮指出最影响识别的具体差异、原因和对应变更，冻结用户已认可的部分。必要时修载体或素材，而不是持续向错误载体增加特效。源码显示分层齐全，只能证明有相应实现，不能证明各层比例和显示结果相似。

没有实机画面时仍完成已授权实现和必要编译，明确“结构／资源已接入，渲染还原未验证”。不以本流程为理由违反目标环境的 Editor、PlayMode 或截图限制，不强制用户提供截图后才交付。
