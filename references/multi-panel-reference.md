# 技能特效生图规范、提示词模板与素材拆解

类型：skill 通用生图规范；范围：Unity 技能特效技术参考板、提示词及独立生产素材；状态：当前有效。

新生成、改版技能特效参考图及仅编写提示词时读取。本文件统一维护通用画风、构图和完整模板，随 skill 一起使用；项目文档只补充专项约束与归档入口。用户要求和具体项目约束优先。默认交付同一技能的多部分技术参考板，以2×2四宫格为常用布局；用户只改某个部件或已有选定单图时，保留其范围，不额外重生整板。

## 生图前确认技能事实

有工程时先核对技能定义与正式执行：目标、位移、作用中心、方向、伤害／恢复／保护种类与触发阶段。只写当前画面需要的事实，不凭技能名臆造机制；旧归档提示词是历史请求，不覆盖现行代码。没有工程时使用用户给出的技能含义，未确定的机制标为设计假设。

单体伤害、单体护盾、突进起步和无地理限制的全队效果不能凭空增加危险范围圈；范围和弹道表现对应真实判定。兽首、幽魂、十字、盾、羽翼等必要意象要保留，不能作为“无关装饰”一并排除。批量任务保持共同风格段一致，每招单独填写设计段并输出自己的参考板。

## 默认画风与构图

统一镜头、材质精度、明暗层次和可读性，各招保留独立轮廓、配色、介质与运动。用户指定镜头或风格时按该目标改写默认值。

| 维度 | 统一要求 |
| --- | --- |
| 画风 | 半写实幻想 3D 游戏 VFX；有厚度和曲率的实体、流体、雾气及碎屑，主体具有可制作的空间结构 |
| 镜头与构图 | 默认单招一张正方形多部分技术参考板，以2×2四宫格展示整体与关键部件／素材。整体格使用45度斜俯视、近似正交；部件格按轮廓、截面或纹理需要使用俯视／侧视／平面展开。每格完整入镜并留出尾迹和飞散空间，主体约占格内70%；部件放大仅供观察，实际装配比例以整体和正式配置为准 |
| 背景 | 整体格使用深灰哑光石砖地面与暗灰背景；拆解格使用干净中性暗灰背景，避免地面纹理与其他层遮挡部件。背景仅供空间和亮度参照，不增加建筑、道具或角色 |
| 层次 | 主体决定辨识度，次级介质表达运动，微粒补充冲击与尺度；不能用大量小粒子掩盖主体造型缺失 |
| 材质 | 具有纹理、宽窄变化、局部厚薄和柔边透明；叶片有叶脉，羽毛有分层纤维，骨面有节段与风化，晶盾有透光切面，气浪有卷动波峰 |
| 亮度渐变 | 各部件分别保留暗部、主色中间调、局部高光与柔边；写清最亮位置、透明边缘和衰减方向，不把整片叶、整张盾、整个兽首提亮成白块。不应发亮的部件明确无闪点／无亮芯 |
| 泛光与粒子 | 泛光克制，高亮集中在刃口、撞击点、局部边缘或少量微粒；中心空腔、主体切面和背景仍可辨认 |
| 排除项 | 无 UI、大标题、水印、无关法阵或符文；允许同一技能的受控技术分格及必要小编号，禁止无关图片拼贴或四个不同设计方案。技能本身的兽首、幽魂、十字、盾、羽翼等必要意象不属于应删除的装饰 |

## 四格分别承担什么

| 格位 | 内容 | 要回答的问题 |
| --- | --- | --- |
| A 左上：整体 | 单个代表阶段的完整组合，保留所有已设计主体、相互位置和实际比例 | 最终组合是什么样，各层在哪里、如何遮挡和配合？ |
| B 右上：主部件 | 最承担辨识的主体独立展示，去掉遮挡它的气雾、碎片和背景贡献 | 如何复现轮廓、厚度、曲率、负空间和截面？ |
| C 左下：另一关键部件 | 实际存在的第二主体或重要伴随介质，完整且清晰地展示 | 哪一层需要独立网格、纹理或序列帧，如何与主体匹配？ |
| D 右下：素材细节 | 剩余关键介质、纹理／透明遮罩组织、尾迹渐变或必要的辅助视角 | 材质内部结构、最亮位置、衰减方向和透明边缘如何实现？ |

部件分配按当前技能决定，不固定要求每招都有法阵、匕首或气雾。简单技能可用剩余格展示同一主体的侧面／截面／纹理细节；复杂技能允许增加分格或补单独素材图，优先保证可读性，不将所有小素材挤在一格。四格不是四个配色方案，也不是四次不同设计。

例如绝影处决可用A组合、B弧形法阵、C细长匕首、D紫雾与尾迹的独立素材示意；D中若含两种介质，清楚分开展示并在文字映射中分别说明。弧纹、匕首的长宽比例、紫色体系和各自亮度关系须与A一致；四宫格默认展示组成而非四个时间阶段；连续六击的时间与方向用文字或后续程序动图说明，不能把静态参考中的余像理解为六把匕首永久同时存在。

## 提示词与选图约束

提示词依次写清用途、共同风格、技能事实、整体代表阶段、分格内容、跨格一致性、配色渐变和专属排除项：

- **共同目标：** 当前技能名称、真实机制、整体代表阶段、画风、各材质的暗部／中间调／高光关系、跨格一致性、留边及布局。整体格按目标战斗镜头；部件格可改为俯视、侧视或近正交细节视角，但注明用途，不能因换视角设计成另一种部件。
- **逐格要求：** 实际部件名称、完整轮廓、轴向、需要看清的结构、材质与透明度、哪些伴随层须隐藏，以及它在整体中的位置和作用。需要纹理展开图时明确是平面材质／遮罩示意，避免模型把它画成另一张三维效果图。
- **一致性：** 每格复用A中的同一造型和配色，不随机增加尖齿、符文、光圈或改变介质。格内可放大细节，但实际长宽比不变；世界尺度和装配比例以A及正式配置为准。
- **可读性：** 格间清晰留白或细分隔线，主体与尾迹完整留边；只允许必要的小编号，说明写在对话或归档中，不依赖模型生成长段文字。共同排除角色、UI、无关装饰与水印；不要再用“禁止拼图”同时否定所要求的技术分格。

修改参考图时提供实际选定图片，明确保留格、部件及本次变化；没有额外要求时保留整体镜头、背景、配色体系和主体身份。

选图时同时检查A的组合及B/C/D对应部件是否一致。主部件缺格、被裁切或与整体明显不同，应修正相关格；不以整图漂亮代替可复现性，也不静默把不同版本的部件组合为当前选图。

## 可复用提示词模板

替换方括号后提交；未知事实保留为明确的设计假设，不填造出的代码数值。部件和材质段按本招填写，不固定要求法阵、武器或气雾。简单技能可将C／D改为同一主体的侧面、截面或纹理细节。

```text
Use case: stylized-concept。
用途：[项目名称] Unity 游戏技能特效多部分技术参考板，一张正方形画布，2×2四宫格，用于AI拆解并复现整体效果及其关键部件、素材。
统一风格：半写实幻想3D游戏VFX；四格来自同一技能、同一设计，造型、长宽比例、材质与配色对应一致，不能画成四种方案。实体与流体层次分明，具有可制作的立体结构、真实纹理、暗部至局部高光的渐变和柔边透明，克制泛光，保留主体轮廓与内部暗面。不要用几条简单发光线充当主体，不要通体白亮。
布局：四格等大，清楚留白或细分隔线，不跨格溢出。每格主体完整入镜，约占格内70%，保留尾迹与飞散空间，可放大细节但不可改变实际长宽比。说明文字另行提供，最多保留必要的小编号A/B/C/D，不添加大标题、段落、UI、水印、角色、建筑道具、无关法阵或装饰符文。
技能：[当前正式名称]。
真实机制：[已从正式定义和执行路径确认的事实，写清对象、中心和方向]。
整体代表阶段：[蓄力／释放／命中／持续中的一个代表性瞬间；不要将不同时刻的全部效果永久叠加]。
A左上·整体效果：[完整组合；45度斜俯视近似正交镜头，深灰哑光石砖地面与暗灰背景，写清主体、次级介质、必要微粒的相对体量、空间位置和前后关系]。
B右上·关键部件一：[实际名称；独立展示完整轮廓、厚度、曲率、截面、朝向、材质与必要空腔；指定最能看清结构的视角；隐藏遮挡它的伴随层，干净中性暗灰背景]。
C左下·关键部件二：[实际名称；独立展示另一主体或伴随介质，写清结构、流向、卷曲、透明度和材质；明确它在A中的位置及作用；干净中性暗灰背景]。
D右下·关键素材／细节：[实际名称和用途；剩余介质、平面纹理／遮罩组织、尾迹渐变或辅助截面，指定展示方式；不新增技能没有的部件；干净中性暗灰背景]。
跨格约束：[逐格部件对应A中的哪一层；保留同一轮廓、配色及内部结构，放大仅供观察，不改变装配比例，不增加随机尖齿、符文或光圈]。
配色与亮度：[各部件分别写暗部色→主体色→局部高光，透明边缘、衰减方向和应保留的暗面；对不应发亮的部件明确无闪点／无亮芯]。
专属约束：[最容易画错的形状或机制；必要意象须保留，排除误导性范围或持续效果]。
```

## 从参考板到实现

将每格映射到实际层的几何／纹理／材质、挂点与正式阶段。若细节图能指导轮廓而不能给出生产素材，就明确它仍是参考图；网格载体和可用纹理仍须制作。

四宫格板不是生产图集，不能整张贴在法阵上，也不能默认裁下任一格即可导入。真正需要透明纹理、平面遮罩或序列帧时，基于选定部件另行生成／编辑独立素材，明确透明背景、视角、UV方向、无地面／烘焙阴影、无格线／文字、完整边缘与寻址要求，并检查输出。板中可展示预期素材组织，但不宣称已获得透明生产文件。

归档保留实际整板与完整提交提示词，记录格位、部件名称、视角、用途和当前选定版本；单独提取或制作素材时再记录实际文件与来源格。旧单图和历史原词保留原样，不追溯重写。交付中区分概念拆解板、独立生产素材、[程序图片／动图预览](code-image-preview.md)和实机画面。
