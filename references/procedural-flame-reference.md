# 无贴图立体火焰：闭合焰瓣与程序燃烧

类型：随 skill 提供的实现参考。适用于用户要求不用贴图、火焰必须有空间厚度，或反馈火像二维卡片、石片、亮边薄片时。也用于复用已认可的火墙／墓火燃烧表现。不要把这条路线强制用于所有火焰：用户指定序列帧、平面风格或已有认可方案时保留其选择。

本次用户认可的方向是：**立体火簇、中心热芯最亮向外渐变、猛烈上涌与翻卷、低几何预算**。这不是流体模拟或体积光线积分，也不等于已完成各平台 GPU 验收。

## 随 skill 携带的代码

- [ProceduralBurningFlame.cs](../assets/procedural-flame/ProceduralBurningFlame.cs)：仅依赖 Unity API；原项目的效果档设置改为 `lowEffects` 参数，原英雄、对象池和任务类型均不需要。
- [ProceduralBurningFlame.shader](../assets/procedural-flame/ProceduralBurningFlame.shader)：URP 程序火焰、地火、低雾和余烬，无图片、序列帧及噪声纹理采样。放在目标工程 `Resources/Shaders/ProceduralBurningFlame.shader`，或将加载改为目标工程的显式 Shader 引用；其他管线需适配坐标与观察方向函数。

代码是本配方参数真源，优先从它调整，不复制旧版高细分参数。原项目正式入口可参考 `ArenaFireWallVfx`、`MageNecromancyReferenceVfx` 与责任文档的“火墙与墓火瘟疫燃烧重做”；使用本 skill 不依赖这些类或原仓库。

## 先分清问题，再改对应环节

| 反馈 | 优先核对与处理 |
| --- | --- |
| 像二维面片，没有厚度 | 检查 X/Z 截面、侧视轮廓及是否整体朝相机。弯曲平面、叠交叉卡片和软边不能代替本方案的闭合三维焰瓣；主体绕场景竖轴固定散布，不随相机转向 |
| 像石片、薄金属或叶片 | 检查扭转是否过强、半径是否高频锯齿化、尖梢是否成为硬三角片。用连续三维中心线与圆周截面保留体量，减少僵硬折面；不要仅提高细分掩盖错误载体 |
| 边缘太硬、整片亮 | 密度和亮度分开。按截面法线与观察方向柔化外轮廓，热芯集中在焰腹，向边缘与上方渐暗；不加 Fresnel 亮壳或横向等宽高亮，不靠整体发白或全局 Bloom 补可见性 |
| 太柔和，像缓慢飘纱 | 加快中心线形变、内部上行流纹和火丝脱离，加强半径收缩及上端侧卷；各簇错开相位，避免整场同步呼吸。猛烈程度不靠增加粒子和焰瓣数量 |
| 地面红条先出、火焰后出 | 若两层应一起燃烧，共用正式起火开关、起火后的局部时钟和淡入进度；等待阶段都隐藏。保留真实施法／生效等待，不为了同步画面提前结算伤害 |

## 三维轮廓与程序材质

每簇由少量根部焰瓣和脱离火丝组成，沿三维中心线布置圆形截面，根部和尖端收束。根部焰瓣绕竖轴散布，X/Z 有相近的实际厚度；中心线在不同空间方向弯卷，半径随高度与局部时钟收缩、膨胀。圆周首尾顶点重复，确保拓扑与流纹在接缝连续。

顶点阶段只算当前中心线点和一个邻点，复用它们计算切线、截面基向量和收束斜率。处理首尾取样边界，分数幂先保证输入非负；保证切线不退化，包围盒覆盖弯卷与完整脱离轨迹。截面背面剔除减少重复透明绘制，地火／烟雾分支可按自身载体使用双面。

片元以局部三维位置驱动流纹，用少量不同方向的程序噪声保留前后层次和上涌。观察方向只控制轮廓柔化与焰腹明暗，不参与主体摆放或让几何朝向相机。热芯的 HDR 增亮独立于密度；火墙可用浅金芯→橙红腹→暗梢，墓火可用薄荷亮芯→青绿腹→紫色外围，按新技能配色整体映射，不保留无关的固定颜色。

脱离火丝沿空间路径向上走，年龄回绕前后覆盖为零，避免突然弹回。主持者传入可暂停的视觉时钟；别在 Shader 中混用不会暂停的全局 `_Time`。它们只负责表现，不额外产生伤害或波次。

## 预算从单簇算到整片

闭合体的成本按 **纵向段数 × 圆周段数 × 2 × 焰瓣总数 × 同时可见簇数** 估计。不要只说“单体网格不大”。还要算顶点形变求值、像素噪声、透明覆盖面积、烟雾重绘与绘制次数；无贴图不自动更便宜。

随附基准：普通档每簇四支根部焰瓣、两支火丝，16×8 细分，共 1536 个三角形；低档三支根部、一支火丝，12×6，共 576 个。它们是可调起点，不是通用最低值。先保留空间厚度与主轮廓，再减少细分、重叠焰瓣和伴随层；不要退回面片。对长墙和圆场分别限制簇数，在目标镜头尺度确定数量与间距，不把每个单元放大到重新填满整屏重叠。

材质、网格和属性块缓存，低档切换重绑缓存网格，不逐帧重建。不要重新引入高细分版本作为未使用备用接口。几何预算、可见画面与实际 GPU 耗时分开说明；三角形减少比例不能作为帧率提升比例。

## 接入方式与验证边界

在主线程取得 `GetVolume(lowEffects)`、`GetMaterial(grave)`，或用 `Create(parent, lowEffects)` 创建未启用的 renderer；绑定材质，设置真实场景位置、固定朝向、宽高和属性块后再启用。`Paint(renderer, localAge, phase, opacity, heat)` 写入每簇视觉时钟和相位。地火、低雾、余烬通过 `Ground/Smoke/Ember` 分支取材质，保持各自正式生命周期。

宿主负责真实起火时间、持续和取消、暂停、对象池复用与粒子清空。持续场创建一次，真实跳伤只增强有限的局部反馈；火墙一类共同燃烧层使用同一淡入曲线。各单元不拥有共享缓存，只有全部消费者停止后的唯一缓存所有者调用 `ReleaseSharedResources()`。

遵循目标项目许可验证：C# 编译不能证明 Shader 导入、透明排序、立体观感或性能正确；有禁止 Editor／PlayMode 的规则时遵守，明确未验收项。用户认可当前结构后，只调整其指出的亮度、运动或时序，保留已认可的体量和预算。
