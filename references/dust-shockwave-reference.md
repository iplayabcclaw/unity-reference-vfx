# 扩散尘浪与可调高度震荡波

类型：可复用特效算法参考。适用：落地冲击、践踏、地震的径向尘浪。状态：本项目已接入公共方法并通过 C# 快速编译；Shader 导入、实机造型和性能未验收。下列参数是造型初值，不是测量得到的真实介质常数。

## 选择与接入

先区分沿地面扩散的尘浪、立体元素气浪、实际地板震动；它们不应因名称相似就统一替换。尘浪只负责可见介质，不负责伤害、地裂、地板形变或镜头震动。由正式命中或周期事件传入真实中心、已解析半径和生命周期；视觉扩散不改变命中时点。

已有公共入口时优先复用，避免为每个技能另写算法。本仓库入口是 `DouYuManager/Assets/Scripts/ImpactPressureWaveVfx.cs` 的 `SpawnDustWave`，曲面缓存位于 `GoldenGroundBurstVfx.cs`，Shader 为 `Assets/Resources/Shaders/QuakePressure.shader`。当前使用技能及完整参数责任说明见 `DouYuManager/Docs/规范/技能特效实现规范.md` 的公共震荡波章节。其他工程按以下公式实现，不依赖这些类。

## 扩散、宽度与浓度

以有效视觉半径 R 归一化空间，归一化时间 t=age/life，限制在 0～1：

- 前沿 `f=(1-exp(-4t))/(1-exp(-4))`，先快后慢。
- 波带尺度 `w=.08+.24f`，随扩散变宽。
- 浓度峰位置 `c=f-.40w`；径向差 `d=r-c`。
- 非对称高斯 `P=exp(-.5*(d/sigma)^2)`，内侧 `sigma=.44w`，外侧 `.23w`：后方拖尾宽，前沿窄。
- 尘量包络 `M=(1-exp(-t/.02))*exp(-t*.6/1.1)*(1-smoothstep(.7,1,t))`。建立、沉降和末段退出随寿命同比缩放。

峰位置保留连续周向起伏：`(.42sin(5a+1.2)+.33sin(11a-.3)+.25sin(19a+2))*w*(.05+.11f)`，只作用于波带形状。所有公共震荡波的表面统一为纯渐变：密度轮廓只使用 `P`，不采样贴图，不加入程序噪声，没有旧纹理模式或逐招开关。波峰至内侧拖尾／外沿的透明度与亮度连续渐淡。

按面积积分归一化纯径向轮廓 I，光学厚度 `tau=P*M*.28/I*density*opacity*tintAlpha`，不透明度 `alpha=1-exp(-tau)`；亮度为 `lerp(.60,1.08,P)`，保留主色，以波峰强调和地板透出表达梯度。普通立体波使用同一渐变材质并保留原网格边缘透明度；贴地尘浪读取上述动态波带，两种载体都没有表面纹理。

不要再叠加多套全局透明度衰减，把主体一起乘没。浓度与亮度是不同变量：提高浓度应增加光学厚度，不应以提高 RGB 或增加亮圈代替。

## 隆起与外翻

高度系数 h 相对 R 定义。实际高度包络为 `H=h*(1-exp(-t/.03))*exp(-1.8f)`；h 并非全过程中的实际峰高。h=0 时保持贴地。

有高度时，把缓存网格的径向参数 u（0～1）映射到移动波带：

- 基础半径 `max(0,f-1.25w+1.65wu+周向扰动)`。
- `p=saturate((u-.05)/.95)`，截面曲线 `q=sin(pi*p)^1.65`。
- 高度 `y=H*q*(.86+.14sin(7a+.5))`。
- 径向外翻偏移 `H*.42*q*p`。

只有移动波带隆起，低拖尾回到地面；不要让整片圆盘同步上下起伏，或把地面做成正弦软波。浓度使用外翻前的径向坐标，避免形变把介质图案拉到另一处；首尾以软遮罩收边。

这是可调的隆起、外翻截面近似，不是完整卷涡或流体仿真。单层透明曲面仍需实机检查前后遮挡，不宣称它具有体积散射。

## 公共参数及当前用法

| 参数 | 语义 |
| --- | --- |
| `density` | 光学厚度倍率，默认1，下限0，可超过1 |
| `opacity` | 0～1，与 tint Alpha 相乘；不是独立的亮度控制 |
| `tint` | 主色 RGB；当前通过 RGB 调亮暗，没有独立 brightness 参数 |
| `heightRatio` | 相对 R 的高度系数，默认0，当前限制0～0.5；实际峰高继续随扩散衰减 |
| `life` | 默认0.6秒，当前最低0.12秒；缩放整个视觉时钟 |

本项目震地狂潮当前调用示例（不是其他技能的统一默认值）：

```csharp
ImpactPressureWaveVfx.SpawnDustWave(center, radius, runtime,
    life: .6f, tint: new Color(.72f, .61f, .45f),
    density: 1.8f, heightRatio: .18f);
```

## 运行成本与验证边界

- 模拟阶段可以逐像素积分以判断造型；运行时不重做二维求解。本项目一次生成129项径向积分缓存，每项96点求积，积分对象为纯径向轮廓，已移除噪声均值系数；每帧插值读取。因此不是逐像素严格守恒。
- 缓存96段×25行单层网格，顶点 Shader 做映射与高度变化；不逐帧重建或上传网格。积分表、材质、网格与对象池复用，池重租时重置浓度、高度和颜色，时钟遵守暂停及任务回收。
- 网格中心保留极小非零半径以保存径向方向；变形后的包围盒必须预留高度及外翻范围，不能使用原平面的零高包围盒。
- 浓度拖尾允许在实际范围外保留淡薄装饰；当前至1.25R软收边。它不是伤害或危险范围标记。高度系数范围改变时同步检查包围盒。
- 当前 Shader 仍逐像素计算高斯、渐变亮度和指数透光，并非已经烘焙成序列图。固定造型可后续烘焙浓度／光学厚度图集并插值播放；可调高度继续由网格表达。需要自由调浓度时，优先保存光学厚度，而不是直接缩放已饱和的不透明度。烘焙节省算术，不消除透明覆盖与采样成本。
- 检查零浓度、零高度、最大高度、开始／结束、池复用和暂停清理；遵守项目验证规则。C# 编译不能证明 Metal Shader 成功或游戏中效果已验收。
